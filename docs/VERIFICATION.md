### 验证边界

本轮不部署业务服务器、不变更个人插件安装，不触发 OAuth 确认、邮件、招新通知或动态发布。工具发现和公共工作台连通不等于已逐一验证全部业务写入。新的本人登录、原生侧栏更新、Windows 桌面和所有独立业务操作没有在本轮实机验收。

既有用户应按 README 更新 GitHub 来源并重新安装；个人私有来源不会被自动替换。回退使用独立旧 tag，不覆盖已有发布，也不删除登录目录。
