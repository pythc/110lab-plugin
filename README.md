# 110lab 插件

110 实验室工作台的 GitHub 安装源，适用于支持本地 MCP 的 Codex 桌面端。

从侧栏进入工作台，使用项目立项、奖项荣誉、招新管理、公共邮箱、动态管理、考核与需求平台。每位成员使用自己的飞书身份，服务端按成员、管理员和超级管理员权限开放功能。

## 安装

准备好 Git、Node.js **20.11 或更新版本**，以及支持 `codex plugin` 命令的 Codex CLI。已验证 CLI **0.160.0**。终端执行 `node --version`、`git --version`、`codex --version` 应正常显示版本。CLI 没有插件命令时请先升级。

在终端依次执行：

```sh
codex plugin marketplace add pythc/110lab-plugin --ref main
codex plugin add 110lab@110lab
```

然后重新打开 Codex 桌面端，在插件目录的 **110 实验室** 来源中确认 **110lab** 已安装。打开新会话，输入“打开 110lab 工作台”，也可以使用宿主显示的 110lab 侧栏入口。

如果当前 CLI 只能添加来源、没有 `plugin add`，执行第一条命令后，在桌面端插件目录选择 **110 实验室 → 110lab → 安装**。

插件已打包运行依赖，**不需要克隆官网仓库，也不需要运行 npm install 或构建**。首次使用的网络请求连接现有 110lab 服务；校园内网应用仍需要校园网络或 VPN。

## 首次登录

1. 打开工作台，点击飞书登录，以自己的实验室飞书账号授权。
2. 在授权页确认连接，浏览器通过本机回调完成登录，返回插件继续使用。
3. 登录最多保留 30 天。关闭、重新打开插件不会主动退出；点击“退出”、凭据撤销或到期后需要重新登录。

“周催办”是现有飞书授权应用的名称，不是共用账号。安装本插件不会授予管理员身份。项目、荣誉、招新、邮箱、动态管理共用工作台身份；需求平台保留自己的首次飞书授权；对外批改系统继续使用其独立账号。

业务 MCP 第一次使用时，还会按所需业务权限请求独立授权。网页已登录不等于全部 MCP 写权限已授权。发送邮件、飞书同步和公开发布等操作仍须按现有流程预览并由本人确认。

## 需求平台的个人 MCP（可选）

工作台和其他业务不需要需求平台连接码。需求平台 MCP 和“我的待办”中的个人需求同步，需要每位成员在需求平台的个人 MCP 连接设置里，生成并按平台指引配置**自己的连接码**。

本机连接文件为 `~/.config/110-requirement-mcp/credentials.json`。沿用平台现有接入流程；文件必须仅本人可读，且包含平台要求的完整凭据格式。未配置时，需求 MCP 会提示“连接码未配置或无效”，个人需求待办显示未连接；这不代表工作台飞书登录失败。

不要发送连接码到聊天、放进 GitHub，或向其他成员复制这个文件。轮换或撤销连接码后重新连接插件。

## 更新与固定版本

更新安装源并重新安装最新版：

```sh
codex plugin marketplace upgrade 110lab
codex plugin add 110lab@110lab
```

更新完成后重新打开插件。请先完成更新，再开始飞书登录，避免更新过程关闭正在等待授权的本机回调端口。不要同时启用原个人私有版和本仓库版，以免出现重复入口或重复工具。

需要固定或回退到本次发行版时：

```sh
codex plugin marketplace remove 110lab
codex plugin marketplace add pythc/110lab-plugin --ref v0.15.1
codex plugin add 110lab@110lab
```

需要再次跟随最新版时，重复上述三步，将 `--ref v0.15.1` 改为 `--ref main`。切换分支或 tag 时必须先移除旧来源，否则 CLI 会提示同名市场已经来自另一个来源。移除来源后重新添加并安装，不要手动删除本机登录目录；此操作不回滚服务器业务数据。

## 常见问题

- **找不到 node**：安装 Node.js 20.11+，确认 `node --version` 可用，再重新打开桌面端，使其读取最新运行环境。
- **找不到插件来源**：检查第一条命令是否成功，重新打开桌面端；也可运行 `codex plugin list --marketplace 110lab`。
- **授权后 127.0.0.1 拒绝连接**：本机插件进程可能被更新或关闭。回到插件重新发起登录，不要刷新旧授权页。
- **飞书提示没有权限**：由实验室管理员确认组织成员身份及业务权限；共享安装包不会绕过这些检查。
- **浏览器或手机不能运行本机桥接**：当前发行包需要桌面本地运行环境，不能直接在网页或手机端运行。

当前验证覆盖 macOS 的插件进程和 Linux 的安装流程；Windows 桌面登录尚未实机验收。

## 包内容与维护

- `.agents/plugins/marketplace.json`：插件目录，来源名称为 `110lab`。
- `plugins/110lab/`：可直接安装的客户端插件，包含已构建的 MCP 桥接与图标。
- `distribution.json`：上游官网仓库提交、插件版本、逐文件 SHA-256。
- `plugins/110lab/mcp/NOTICE.txt`：打包依赖的第三方许可。

仓库只分发客户端文件，不包含飞书 App Secret、邮箱密码、个人 OAuth 凭据、候选人材料或生产数据库。登录凭据保存在使用者自己的电脑，插件更新不会把这些文件带进仓库。

安装说明依据 [OpenAI 插件安装源文档](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli)，维护步骤见 [维护说明](docs/MAINTAINING.md)。
